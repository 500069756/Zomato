# Phase 3 LLM Integration

This folder contains the Phase 3 implementation plan for integrating Grok LLM into the recommendation pipeline.

## Goals
- Load and format candidate restaurant data from Phase 2
- Construct prompts for Grok to rank and explain recommendations
- Load the Grok API key from a `.env` file

## Files
- `llm_integration.py`: placeholder for Grok prompt builder and API client
